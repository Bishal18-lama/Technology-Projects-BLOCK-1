# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU | Executes instructions, performs calculations, and controls the operations of the computer. | Clock speed (GHz), number of cores, and number of threads. |
| RAM | Temporarily stores data and programs currently being used by the computer. | Capacity (GB), speed (MT/s), and memory type (e.g., DDR4 or DDR5). |
| Storage | Stores the operating system, software, and files permanently, even when the computer is switched off. | Capacity (GB or TB), type (SSD or HDD), and read/write speed. |
| Motherboard | Connects the computer's components and allows them to communicate with each other. | Form factor (e.g., ATX or Micro-ATX), CPU socket, and supported RAM type. |
| Power Supply | Converts mains electricity into the voltages required by the computer's components. | Power output (watts), efficiency rating (e.g., 80 PLUS Bronze), and connectors. |
| Cooling | Removes heat from components to prevent overheating and maintain performance. | Type (air or liquid cooling), fan size (mm), and cooling capacity. |
